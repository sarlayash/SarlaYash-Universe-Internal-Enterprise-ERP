## 🏛️ System Overview

**SarlaYash Universe ERP** is an enterprise-grade internal web portal designed for the team, solution engineers, leadership, and interns of SarlaYash.

### 🌟 Core Capabilities
- **Role-Based Authentication & Instant Persona Switcher:** Switch between Founder, CEO, CPO, and Solution Engineers in 1 click or log in with credentials (`sarlayash123`).
- **Dynamic Employee Dashboards:** Personalized greeting, live IST clock, check-in widgets, and performance metrics.
- **Daily Attendance Hub:** Shift tracking (09:30 AM – 06:30 PM), work mode selection (*Office*, *Remote/WFH*, *Field/On-Duty*), task notes, and Admin CSV export.
- **Leave Management & Approval Desk:** Quotas for Casual Leave, Sick Leave, Privilege Leave, and **SarlaYash Blessings Leave** with instant manager approval workflows.
- **Interactive Enterprise Calendar:** Visual monthly calendar showing official national/festival holidays, corporate milestones, live YouTube masterclasses, and approved team leaves.
- **Organizational Hierarchy & Directory:** Interactive visual tree and directory of all 10 core members with reporting lines and contact details.
- **Social Media & Broadcast Command Hub:** Tracks **18 official channels** across LinkedIn (7), YouTube (6), and Facebook (5), including assigned channels like *AI Ladder 🪜 With Kapil*.
- **SarlaYash Blessings — Internships Earning Model:**
  > *“ Choose your target. Create the impact. Prove the results. Earn your reward. 🚀 ”*
  > Interactive milestone tracker with reward tiers (*Silver, Gold, Diamond Champion*) and verified proof submissions.
- **Salary Statements & Payslip Portal:** Formatted company salary statements with earnings breakdown, blessings incentives, deductions, and print-to-PDF layout.
- **Notice Board & Compliance:** Official bulletins and POSH (*Mysteries Of POSH With Kapil*) safety and ethics policies.

## 🛠️ Tech Stack & Architecture
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS + Obsidian & Imperial Gold Corporate Aesthetics
- **Icons:** Lucide React
- **Celebrations:** Canvas Confetti
- **State & Storage:** Reactive Browser LocalStorage with automatic seed hydration and full CRUD operations.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/sarlayash/SarlaYash-Universe-Internal-Enterprise-ERP.git

# Enter project directory
cd SarlaYash-Universe-Internal-Enterprise-ERP

# Install dependencies
npm install

# Start local development server
npm run dev
```
